# 专业课程文字讲解

## 已确认的默认设置

- 覆盖用户本次提供的全部材料，保留教学主线；只补充理解材料必需的前置知识和紧密关联。不自动缩为一章，也不扩展成整门学科。材料过大时说明范围与工作量，询问分批方式，不默默省略。
- 交付的是可以从头连续读完的教师讲授稿，以文字为主，公式、图片与交互辅助讲解。保持课程的完整知识骨架和定义顺序，学生基础、困惑和重难点只调整详略、先修补讲、例子与强调；不能据此跳过课程概念、核心推导或算法步骤。用户明确缩小材料范围时按其指定范围完整讲解。
- 中文讲解，首次专业术语附常用英文；目标是本科课程深入理解与问题分析。课程内知识仍须解释；已知的外部先修可简短回顾，不能将“学过编程”推断为已掌握待讲算法。
- 一个完整 HTML，样式、基础交互、图示与图片内嵌；公式允许固定版本 KaTeX CDN 排版。阅读和基础交互不依赖网络、服务器、模型接口或 Codex 宿主。
- 常规配色、字号、布局沿用模板。影响范围、理解或结论的不确定必须询问；已明确的信息不重复询问。
- 独立学习者档案跨课程复用，无须额外笔记系统、网站发布或大型工程。
- 静态正文支持选中文字高亮、下划线与评注、本机浏览器保存及笔记导入/导出。公式与动态演示不改写；支持边界和存储失败要如实说明。功能依据见 [references/annotations.md](references/annotations.md)，不让标注界面抢占课程正文。

## 开始与澄清

1. 明确材料清单和边界。可先读取索引、元信息和少量样页判断格式与规模。
2. **输出路径缺失必须询问并等待回答。** 给的是目录，则在该目录生成描述性 `.html` 文件；不默认写当前项目、材料旁或技能目录。明确路径前仅在临时工作区识别材料，不生成最终课程文件。
3. 读取学习者档案中本课相关记录，结合对话核对先修基础、已有理解、具体困惑与目标。当前用户表述优先。背景不足时集中问一轮，不用专业或年级推断掌握程度；不能自评时可给少量诊断题，等回答后调整详略，不能削掉完整课程主线。
4. 材料、路径、基础和困惑明确就完成任务，不额外要求提纲审批。只问实际缺失或冲突的信息，同时推进不受影响的工作。

## 学习者档案

- 路径为 `$CODEX_HOME/learning-profiles/course-principles-html.json`；未设置 CODEX_HOME 时用 `~/.codex/learning-profiles/course-principles-html.json`。档案位置与课程输出路径是两件事。
- 缺失时从 [assets/learner-profile.template.json](assets/learner-profile.template.json) 初始化；未知项留空。已存在则先读取再合并，不覆盖其他课程。保存确认过的偏好、学生自述基础和困惑。
- `knowledge_records` 记录主题、学生表述、证据类别、日期及待核对情况。区分 `user_reported` 和 `demonstrated`；单题表现不能推断整门课熟练。
- 页面生成、阅读勾选、展开答案都不是掌握证据。独立 HTML 点击不会自动回传，只按用户后续反馈更新档案，不承诺后台同步。旧记录是待核对线索，不能当作当前掌握情况。
- 写入采用读取、合并、临时文件替换方式，遵守实际权限。不要把完整私人档案嵌入学习页面。

## 材料与证据

按格式需要读取 [references/materials-and-evidence.md](references/materials-and-evidence.md)，不加载所有技能或整套手册。

- 建立内部教学映射：材料定位 → 必讲概念/定义/公式/算法/伪代码 → 前置依赖 → 正文位置 → 例子/应用。复用提取结果，覆盖所有教学内容或说明重复、无教学内容、不可读取的情况。图中的伪代码、公式和流程图也属于正文内容，不能因文字提取不到就省略。
- 课程讲述顺序是主线，必要先修补讲放在首次使用之前。知识连接说明具体依赖、递进或条件变化，不只列关联词。
- 关键缺口、疑似错误和软件/硬件版本差异才针对性查证；优先教材、原论文、官方文档。普通明确事实无需逐项搜索，不批量搜无关论文。
- 模糊公式、读不到的图表或影响结论的材料冲突，先查原图或权威来源；仍不明就询问并等待依赖内容澄清。不猜测、不伪造出处、不静默更正。

## 专业讲解

写作时读取 [references/teaching-and-html.md](references/teaching-and-html.md)。

- 按材料主线从问题、概念与定义展开，符号和对象先于公式，定义与规则先于算法，算法先于运行演示，相关方法讲完后才综合对比。不能开场展示尚未讲过的多算法控制台，不能用互动代替核心说明。
- 课程提供的算法伪代码必须展示，保留其变量、输入输出、控制流与来源；核心伪代码默认可见。逐行或按逻辑行组解释初始化、选择、终止、生成、更新、剪枝及返回，与一个完整可复查的例子对应。替代语言实现不能冒充原伪代码。材料没有伪代码时才整理补充版并标明来源依据。
- 课程核心定义、关键步骤、条件和结论必须在主文清楚呈现。所有重要公式/伪代码符号在首次使用附近解释对象、取值/单位及角色；区分状态/节点、实际值/估计值、单步/累计值等有教学意义的差别。
- 关键推导交代每一步依据，不只罗列式子。区分蕴含、必要/充分条件、统计相关/因果证据；算法保证带条件。用先修搭桥，但不无限补讲外部课程。
- 重点分为“定义”“关键步骤/结论”“成立条件”“易错点”，在对应位置统一标识。比较表说明比较维度及最重要差异，不能把关键结论混在普通描述里，也不能给每段都加重点框。
- 标题用准确的课程术语与教学对象，目录显示完整逻辑层级。正文只写帮助理解当前知识的讲授内容；删除口号式标题、制作说明、无关提醒、反复纠错和泛泛的保证。来源校订有必要时简短说明，不打断主线。
- 核心伪代码、定义和决定结论的推理不放入默认折叠区；长实现、重复计算、完整证明的补充细节可折叠，但关键内容保持可读。无法关闭交互来读懂正文则尚未完成。
- 自测侧重条件识别、过程预测、方法选择、反例或迁移，反馈解释理由。交互必须确实改变结果或展示。
- 既有实验注明来源，自建演示标“教学模拟”；必要时才做小型可复现实验，不能把示意图说成研究结果。

## 生成 HTML

1. 临时写 `lesson-meta.json` 和 `lesson-body.html`，格式与组件见教学参考。先写课程内容，再套模板，不每次重写样式和基础交互。
2. 元信息包含 `title`、`scope`、`sources`、`teaching_units`；格式见教学参考。`learner_note` 可保留作内部记录，默认不显示在课程开篇。教学映射记录必讲内容、依赖、算法伪代码/符号说明/例子锚点；构建器校验位置及可见性，但不替代专业审阅。
3. 正文只写 HTML 片段，各主章节有唯一 `<h2 id="...">`。公式用 `.math`；优先内嵌 SVG，课程图片按需内嵌 data URL，不复制来源网页脚本。动态演示外层标 `data-no-annotate`。模板自动内嵌标注资源，独立于联网公式排版。
4. 组装命令（换成实际绝对路径）：

   `python3 <skill-dir>/scripts/build_lesson.py --meta <meta.json> --body <body.html> --output <用户指定目录/课程.html>`

   脚本拒绝相对输出路径和未经选择的覆盖。用户明确要求更新既有文件时可加 `--overwrite`。
5. 按需添加少量原生 JS 的参数或分步演示，局部计算即可；不增加重型框架、收费接口、追踪或后台服务。

## 验证与交付

- 运行 `python3 <skill-dir>/scripts/check_lesson.py <绝对路径.html>`，检查结构、锚点、组件和单文件资源约束。脚本不验证专业内容与浏览器排版，不能把通过当作教学验收。
- 先做教学验收，再做页面验收：对照教学映射逐项检查完整覆盖、前置顺序、符号定义、原伪代码及行组解释、可复查例子、推导依据、应用与重点。再检查实际运行结果和交互。学生提出一个卡点不意味着其他部分可以略过。
- 去掉/不操作交互后从头通读，检查是否仍是一份连续、全面的课程讲解；检查标题、段落和强调是否服务教学。结构脚本通过或按钮能点不代表教学质量合格。
- 有浏览器时实际查看桌面与窄屏、代表性公式、可见伪代码、重点标识、折叠/自测、自定义主要交互与文字标注，修复观察到的问题。标注至少验证选取、保存重开、编辑删除及导出/导入；无浏览器时说明未验证的功能，不声称视觉或标注已验证。
- 公式网络资源失败时保留可读原始公式和提示，阅读与基础交互继续工作。正常加载也检查 `.math-error`，修复解析错误。
- 最终给 HTML 绝对路径链接，简短说明材料范围、个性化侧重、检查与实际限制；可在 Codex 文件面板展示，不擅自发布网站。
- 节省额度：复用模板、提取结果和来源定位，只读相关参考；默认不多代理重复写课程、不无目的重写或重复已通过检查。重大推导或复杂交互才做范围有限的独立核验；不以节省掩盖遗漏。
